## Fitting, ranking and thresholds

B0 is a prior Dummy; B1 is unweighted LR with fold-local StandardScaler; B2 unweighted RF; B3 actual unweighted XGBoost. B1–B3 use seeded RandomizedSearchCV with AP and the same saved 3-fold training splits. There is no RF fallback for XGBoost. A1 reuses B3 parameters and fits training-derived weighting; there is no separate weighted search. A2 shares A1's fitted model/probabilities.

Positive-class F2 (beta=2) replaces V2 F1 threshold selection throughout active A4/A5. Search is exactly ascending `np.linspace(0.01,0.99,199)`; exact ties favor the smallest threshold, without a numerical tie tolerance. Evaluation uses `score >= threshold`. A2 and selected A3 use their validation thresholds; baseline rows retain 0.5; FINAL uses its locked validation F2 threshold even if a baseline wins. Separate reference CSVs retain every evaluated model at 0.5. AP remains the ranking metric and is invariant to threshold-only changes, as is ROC-AUC. F1 remains a secondary reported metric; the old F1 helper is historical QA only.

## A5 locked comparisons and provenance

A4 writes source/protocol/environment/effective settings and artifact hashes, then binds pre-test artifacts with a selection lock. A5 verifies hashes before trusted pickle loading, verifies cases/labels/folds, actual XGBoost internals, primary selector fold/full sets and recorded threshold decisions, then recomputes scores. It validates the locked model decision without invoking selection or fit routines. Schema v3 requires fresh A4/A5 run IDs; stale v2, mismatched split/source/environment and historical LightGBM artifacts cannot be reused.

Exactly three core pairs use one row-resampling stream: B2−B1, B3−B1, FINAL−B3. Original test labels/source positions are required. Seed 42; 1,000 attempts; exclude and log single-class draws without replacement; observed point deltas; 95% marginal percentile intervals. Positive delta favors the left model. Comparison IDs bind run/cases/labels/split/models/score hashes. FINAL=B3 is explicitly an uninformative same-model zero-delta comparison. Intervals condition on fixed fitted models/test rows and do not cover full training uncertainty or imply equivalence. A1 weighting and A3 reduction pairs remain separately approved secondary work, disabled in the core family.

SHAP explains positive-class probability through the final complete pipeline with defaults 500 test rows / 100 training background rows. Sampling, sorted local positions, original source IDs, seed 42, mask/prediction batch bounds, chunks and attribution metadata are saved; budgets are adjustable by CLI/V3 config. Actual counts cap at available rows. An explicit Independent masker sets `max_samples` to the actual selected background count, avoiding SHAP's automatic 100-row cap when larger backgrounds are configured. LIME's distinct perturbation count remains 1,000. Real SHAP/LIME runtime success is unverified; controlled tests verify configuration/sampling/provenance only. Explanations are prediction associations, not causal effects.
