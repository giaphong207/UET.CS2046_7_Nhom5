# Fix A4/A5 artifact integrity and reproducibility; validate the research scaffold

A5 previously accepted predictions, decision thresholds and split indices inconsistent with the serialized final model. The audited scaffold also lacked an immutable runtime/protocol snapshot and could evaluate only four Logistic Regression configurations while reporting a budget of ten.

The resulting implementation verifies critical checksums before loading trusted models, validates the complete split/model/feature/threshold contract, and recomputes model scores before analysis. A4/A5 record protocol, effective configuration, fixed learner parameters, distinct search effort, environment, source hashes and linked run identities. Logistic Regression searches ten meaningful L2 regularization strengths and reports finite-space exhaustion honestly. Dataset domains/diagnostics, subgroup schema, bootstrap disclosure, quick source-row mapping and nested notebook paths are covered by regressions. The current ANOVA/train-fit feature procedure and existing final-model tie order are documented explicitly.

Validation on macOS Intel/Python 3.11: **70 tests passed (62 new cases)**, Python compile and notebook structure checks, dependency consistency/import checks, both CLI help/error checks, and a clean synthetic CLI A4→A5 quick run. Twenty-five independent semantic artifact fault cases were rejected before analysis output; checksum validation was separately tested before unpickling.
