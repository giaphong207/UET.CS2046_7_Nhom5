# Dữ liệu nghiên cứu

1. Tải **Diabetes Health Indicators Dataset** từ https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset.
2. Giải nén và đặt file đúng tên `diabetes_binary_health_indicators_BRFSS2015.csv` vào `data/`.
3. **Không ghép** với `diabetes_binary_5050split_health_indicators_BRFSS2015.csv` hay `diabetes_012_health_indicators_BRFSS2015.csv`.
4. Không thay đổi nhãn hoặc xóa các mẫu có vector đặc trưng trùng nhau một cách tự động.
5. File CSV **không nằm trong gói** và được `.gitignore` để tránh commit bản sao dữ liệu lớn.

Nguồn: Kaggle/alexteboul, dữ liệu xử lý từ CDC BRFSS 2015. Mục đích nghiên cứu học thuật; không phải công cụ chẩn đoán.
